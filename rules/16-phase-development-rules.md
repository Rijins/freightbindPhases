# Phase Development Rules

Version: 1.0

Status: Mandatory

---

# PURPOSE

FreightBind AI is built incrementally.

Every phase must build on previous phases.

Nothing should ever be rebuilt from scratch.

Every phase should make the project feel closer to a production SaaS platform.

---

# PHASE ORDER

OpenCode CLI must NEVER skip phases.

Example

Phase 01

↓

Phase 02

↓

Phase 03

↓

...

↓

Phase 10

---

# BEFORE STARTING A PHASE

Always

Read every rule

Analyze existing code

Understand previous phase

Identify dependencies

Check architecture

Review current UI

Only then begin implementation.

---

# NEVER

Never rebuild completed features.

Never duplicate functionality.

Never redesign existing architecture.

Never change APIs without reason.

Never remove completed work.

Never regress functionality.

---

# PHASE OBJECTIVE

Every phase must have

Backend objective

Frontend objective

UI objective

UX objective

Performance objective

Testing objective

Completion checklist

---

# EACH PHASE MUST DELIVER

Working backend

Working frontend

Responsive UI

Animations

Loading states

Error states

Empty states

Production-ready code

No placeholders

---

# UI EVOLUTION

Every phase must visibly improve UI quality.

The UI should become more premium after every phase.

Never leave a phase with unfinished layouts.

---

# ROLE SUPPORT

Every phase must respect

Admin

Logistics Director

Carrier Dispatcher

Hub Operator

No feature may bypass RBAC.

---

# FILE MODIFICATION

When updating existing files

Modify only required sections.

Preserve formatting.

Preserve architecture.

Preserve readability.

---

# NEW FILES

Every new file must include

Correct path

Correct imports

Correct exports

Reusable structure

Consistent naming

Documentation where needed

---

# FEATURE COMPLETION

A feature is complete only if

Backend works

Frontend works

UI polished

Responsive

Animated

Accessible

Validated

Tested

---

# BUG FIXES

Bug fixes must

Find root cause

Apply smallest safe fix

Avoid regressions

Preserve architecture

Never introduce temporary hacks.

---

# END OF PHASE

Before marking a phase complete verify

✔ Backend complete

✔ Frontend complete

✔ UI complete

✔ UX complete

✔ Responsive

✔ Animations

✔ Security

✔ Performance

✔ Testing completed

✔ Rules followed

# PROJECT GOAL

By the final phase FreightBind AI should feel like a premium enterprise logistics platform comparable to modern SaaS products.

Every phase should move closer to that goal.

Never move backwards.
