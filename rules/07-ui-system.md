# FreightBind AI UI System Rules
Version: 1.0

This project MUST look like a premium SaaS product.

Never generate generic dashboards.

--------------------------------------------------
1. Design Language
--------------------------------------------------

Design Style:
- Modern SaaS
- Enterprise
- Premium
- Clean
- Professional
- Apple + Linear + Stripe inspired

Never use:
- Random colors
- Bootstrap style layouts
- Outdated admin templates
- Plain tables without styling
- Large empty white areas
